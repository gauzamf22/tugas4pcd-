ABSTRACT A recurring question in applied image analysis is not whether a classifier can be trained,
but which description of the image carries the decision. This work answers that question for three
inspection settings solvable without learned representations: a surface defect, a cytological typing task,
and an agricultural grading task. For each we survey the morphological, edge, and representation operation
families, implement a complete pipeline, and ablate the descriptor set. Concrete cracks are recovered by
gradient magnitude and Otsu thresholding, cleaned by opening and closing, filtered by component area,
and described by ten shape features of which logged skeleton length and component count are decisive;
on 1600 images the pipeline reaches accuracy 0.970 and crack-class F1 0.970, with a measured width of
16.5 pixels. A foreground-area rule fails here: median mask coverage is 44.9 percent for uncracked against
9.2 percent for cracked surfaces, the opposite of the intuitive direction. White blood cell nuclei are isolated
by a guarded ratio-color enhancement with an ellipse-expanded cell body, and thirteen region and intensity
features with a linear discriminant reach accuracy 0.596 over four subtypes. Rice grains are described by
nine shape measurements, seven Hu moments, and an eight-bin chain-code histogram, where shape alone
reaches macro-F1 0.961 while the full 24-feature vector falls to 0.955. Feature suitability is thus set by the
task type rather than the object domain, and a descriptor invariant to the wrong transformation adds variance
instead of information.

I. INTRODUCTION
D
IGITAL image processing (DIP) is often presented as
a set of operators to be memorized, but in practice
the operators are chosen by the question being asked. A
pipeline that asks where an intensity discontinuity lies needs
a derivative estimator and a decision rule on its magnitude.
A pipeline that asks which object is present needs a re-
gion description that is invariant to the object’s position. A
pipeline that asks which category the object belongs to needs
a description whose variability within a category is smaller
than its variability between categories. The three questions
are different, and the third assignment block of the course
makes the distinction concrete by separating morphological
processing, edge-based feature extraction, corner and line
extraction, and edge-based feature representation.
This paper takes that separation seriously and tests it. We
select three cases that are solvable by classical techniques
alone, one for each of the three question types above, and
for each case we (i) survey the operation families that the
literature uses, (ii) build a complete pipeline from those fam-

The first case is surface defect inspection: detecting and

ellipse fitting for the cell boundary, and a feature vector

discriminant analysis and naive Bayes; it therefore isolates
exactly the feature families this assignment is about.
The third case is agricultural grading: classifying rice vari-
eties from single grain images. Cinar and Koklu [7] describe
the morphology-and-moment feature set that we adopt, and a
later deep-learning study on the same data [11] provides the
contrast that motivates keeping the classical branch in scope
here.

• a complete, reproducible classical pipeline for crack

• a nucleus segmentation and four-class subtype classi-

B. COMMON PREPROCESSING
Every pipeline begins with colour conversion to a single
intensity channel, because the operators used downstream
are defined on scalar images. Conversion to luminance is
followed by Gaussian smoothing, which suppresses sensor
noise before any derivative is taken; the kernel is 5 × 5 with
σ derived from the kernel size, and the choice is held constant
across cases so that differences between cases are attributable
to the descriptors and not to the smoothing.
Global thresholding uses Otsu’s method [1], which
chooses the threshold that maximizes the between-class vari-
ance of the intensity histogram. Its appeal here is that it
is parameter-free, so a pipeline built on it has no tuned
threshold to leak information from the test data. Where a
case requires contrast normalization, histogram equalization
is applied after the colour-ratio enhancement rather than to
the raw channels, so that the enhancement’s dynamic range
is what gets equalized.

that structure, so we cite them as surveyed alternatives rather
than as components.

F. CLASSIFIERS AND PROTOCOL
Three classifier families are used, chosen to match the refer-
ence methods rather than to maximize accuracy. Linear dis-
criminant analysis projects onto the direction that maximizes
between-class over within-class scatter and is the classifier
of the reference cell method; Gaussian naive Bayes models
each feature independently per class and is the reference
method’s second comparator; the k-nearest-neighbour rule
and a linear support vector machine cover the grain case,
where the classes are expected to be separable by a simple
boundary in descriptor space.
All reported scores are five-fold stratified cross-validation
with a fixed seed, so every image is predicted exactly once
by a model that did not see it. For the crack case, where
the measured quantity is a mask rather than a class label, the
same protocol is applied to the image-level decision rule, and
the threshold that converts a mask into a decision is selected
on one half of the data and reported on the whole subsample
so that the selection is visible.

The interesting measurement of this case is that a
foreground-area decision rule fails here, and it fails silently.
If an image is declared cracked whenever its cleaned mask
covers more than a fixed fraction of the frame, every image
is declared cracked, because thresholding a concrete surface
marks texture as readily as it marks a crack: measured on
the subsample, the median mask coverage is 44.9% for
uncracked surfaces and 9.2% for cracked, so the classes differ
in coverage in the opposite direction from the intuition that a
crack adds foreground. What separates them is not how much
is marked but how it is shaped: the median component count
is 7 for uncracked and 1 for cracked surfaces, and the median
skeleton length of the largest component is 1728 pixels for
uncracked against 280 for cracked, because on a cracked
surface the crack survives cleaning as one long connected
structure while on an uncracked surface the texture survives
as many short blobs.
The operating rule is therefore a classifier on the ten-
element descriptor of Section II-E, fitted per mask stage so
that the stage ablation compares like with like. The decision
is made by a depth-four decision tree, which is deep enough
to express the shape-versus-count interaction above and shal-
low enough that its splits remain readable.
Table 2 ablates the three mask stages on the full subsample,
with the same depth-four rule refitted at each stage. The result
is the opposite of the usual morphological claim and is worth
stating plainly: the raw threshold scores highest, and each
subsequent cleaning stage costs a fraction of a point. The
reason is that the descriptor set already contains the shape
information that cleaning is meant to supply. Skeleton length
per frame diagonal carries 0.94 of the tree’s total importance,
and that quantity is measured on the largest component, so
opening, closing, and area filtering – all of which exist to
shrink small components and fuse large ones – change a de-
scription that is already dominated by the largest component.
On this collection morphology is therefore clean-up that a
downstream consumer would want (a human inspector looks
at a mask, not at ten numbers) but not an accuracy gain, and
reporting it as one would be a claim our measurement does
not support.

Crack width is measured on true positives by sampling
the Euclidean distance transform along the skeleton and
doubling the mean distance, which yields 16.5 pixels. This
figure is deliberately left in pixels. The collection publishes
no physical calibration, the crops carry no scale reference,
and converting to millimetres would require assuming a field
of view; reporting a millimetre value would be an invented
number rather than a measurement.
The descriptor importances of the fitted tree are the direct
answer to which features are suitable here: skeleton per
diagonal carries 0.94 of the total importance, while roundness
and eccentricity together contribute under 0.04. That ordering
is what the task implies. A crack is identified by a connected
structure of sufficient length, and its precise outline is ir-
relevant, so descriptors that encode outline detail are dead
weight while the length and count of connected components
are decisive. Logistic regression on the same ten descriptors
reaches 0.981 five-fold accuracy against 0.970 for the tree,
so the decision boundary is nearly linear in log-area and
skeleton length, and the tree’s advantage is interpretability
rather than capacity.
B. CASE 2
The cell pipeline follows the reference method [6] with two
documented deviations. The reference enhances the nucleus
by the colour ratio (R + B)/(2G), which is large where the
nucleus is dark purple and the cytoplasm is pale. On this
collection the crops contain a black padding frame, where
G = 0 and the ratio is undefined, so the denominator is
guarded as (R + B + 1)/(2G + 1) and the result is clipped
to its 5th and 99th percentiles before scaling. The frame is
additionally removed by cropping to the bounding box of the
largest bright component. The clip limits are not cosmetic:
the unguarded ratio reaches values above 50 on a handful
of specular pixels against a median near 1, so a 1–99 clip
pins both ends of the ramp and the thresholded nucleus
collapses. Histogram equalization is deliberately not applied
after the enhancement, because the ratio histogram is nearly
unimodal and equalization pushes the cytoplasm above the

from eosinophils to neutrophils, followed by lymphocytes to
monocytes, so the errors follow the two pairs whose nuclei
are closest in size and granulation rather than spreading
across all four subtypes.
The errors are structured rather than uniform, and they do
not follow the granulation axis as one might expect from the
stain alone. Eosinophils and neutrophils exchange the most
images, and lymphocytes and monocytes the second most,
while monocytes are otherwise recovered well. Because the
discriminating features here are area, area ratio, and entropy
rather than outline detail, a neutrophil whose segmented
nucleus merges two lobes into one component is described
almost exactly like an eosinophil, and the intensity statistics
do not separate them because both are densely granulated.
This is the measured limitation of a largest-component de-
scription on lobed nuclei.

Table 7 is the paper’s answer to the assignment’s question. It
maps each case to its task type, the descriptor family that
carried the decision in our measurements, and the failure
mode we actually observed.
Three regularities hold across the cases.
First, the useful feature complexity tracks the task’s de-
cision boundary, not the object’s visual complexity. The

crack decision is essentially one-dimensional, a thin structure

reaches 0.970 five-fold accuracy, matching the hand-built

0.961 while the full 24-feature vector falls to 0.955. Adding
descriptors helped in neither case; what helped was choosing
the descriptor whose invariances match the class difference.
Second, the morphological structuring-element size is a
statement about the object’s scale and must be chosen before
the descriptors, not after. Opening with a 3 × 3 element
removes crack speckle without eroding the crack, but a larger
element would delete the crack itself, since the crack width
measured in Section III-A is only 16.5 pixels. In the cell case
the element must be large enough to bridge nuclear lobes,
and the ellipse expansion factor that defines the cell body
is set by the cytoplasm’s extent rather than by the nucleus,
which is why a dark-pixel intersection failed: the nucleus is
the darkest structure in the image.
Third, the descriptors that failed are informative, and one
failed for a reason worth stating. The chain-code histogram
is the boundary descriptor the course block develops in most
detail, and it was the weakest grain group at 0.523, because a
perimeter-normalized curvature histogram cannot encode the
one property that separates these varieties, the axis ratio. Har-
ris corners and Hough lines, surveyed in Section II-D, were
not used at all: concrete cracks, cell nuclei, and rice grains are
not junction- or line-structured objects. The general lesson is
that a descriptor is suitable when the transformation group it
is invariant to contains the nuisance variation of the data and
excludes the class difference, and that this can be decided
from the class definition before any classifier is trained.
V. CONCLUSION
Three classical pipelines were built for three different in-
spection questions and measured on public data. Crack de-
tection reaches accuracy 0.970 and F1 0.970 from gradient
analysis, Otsu thresholding, morphological cleaning, and a
ten-feature shape descriptor, with a measured crack width of
16.5 pixels, and the experiment shows that the foreground-
area rule which this task usually suggests is actively wrong
on real surface texture. White blood cell subtyping reaches
accuracy 0.596 with region and intensity features under a
linear discriminant, after a guarded colour-ratio enhancement
of the nucleus and an ellipse-expanded cell body. Rice vari-
ety classification reaches macro-F1 0.961 from nine shape
measurements alone, and the ablation shows the combined
24-feature vector falling to 0.955: the Hu moments and
the chain-code histogram contributed variance rather than
separation because the varieties differ in a global proportion.
Across the three cases the descriptor family that worked was
predicted by the task type rather than by the object domain,
and the descriptor that failed always failed by being invariant
to the wrong transformation.
Learned feature hierarchies are out of scope here by the
assignment’s constraints, and the natural next step is to use
these classical descriptors as the interpretable baseline that a
convolutional model must beat, rather than replacing them.
